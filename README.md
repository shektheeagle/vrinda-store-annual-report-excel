# Vrinda Store Annual Sales Report

## Project Objective
The objective of this project is to analyze Vrinda Store's annual e-commerce sales data using Microsoft Excel and present key sales patterns through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Data analysis and visualization
- Slicers and filters

## Project Overview
This project explores sales and order data across different categories, customer demographics, sales channels, months, and states. The dashboard helps users explore the available data and understand sales performance.

## Key Features
- Interactive sales dashboard
- Sales and order analysis
- Category and channel comparisons
- Monthly and state-level analysis
- Charts, filters, and slicers
